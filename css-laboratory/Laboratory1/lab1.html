My First CSS Page

CSS stands for Cascading Style Sheets. It is used to style and design HTML pages by changing their colors, fonts, and layout.

CSS makes websites more attractive and easier to read. It also helps developers maintain a consistent design across different pages.

Reflection

1. Inline CSS is written directly inside an HTML element using the style attribute. Internal CSS is written inside a style tag in the HTML file. External CSS is written in a separate CSS file and linked to the HTML document.

2. I would use external CSS for a website with multiple pages because one stylesheet can be connected to different HTML files. This makes the design consistent and easier to update.
